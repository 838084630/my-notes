# 2024年 - 現在

## 株式会社リーディングソリューション / プラットフォーム開発部

- 担当業務：DataCraft Platform の開発・保守、AWS/Azure 環境の構築・運用、Datadog による監視設計、Terraform によるクラウドリソース構築、商用環境リリース対応
- 具体的な成果：Kafka と Flink を利用したリアルタイムデータ処理基盤の構築・改善、障害調査、性能改善、顧客向けデモ対応
- 使用技術：Java、Vue.js、MySQL、Cosmos DB、Flink、Kafka、Datadog、AWS、Azure、Terraform

## 実績

- IoT デバイスから収集した大量データをリアルタイム処理し、クラウド上で配信・蓄積するデータ連携基盤を担当
- 画面設計・仕様検討・非機能試験・商用リリース対応・障害調査を行いながら、運用品質を継続的に向上
- Datadog 監視項目の整備、Terraform による構成管理、AWS/Azure 環境の保守により、案件の安定稼働に貢献
