# 2020年 - 2024年

- 担当業務：EAJ Platform System、ERICSSON IoT Platform Data Migration、NTTCOM カーボンマネジメントプラットフォーム（CMPF）の新規開発・導入支援
- 具体的な成果：詳細設計、共通部品実装、画面開発、バックエンド開発、単体試験、結合試験、性能試験、障害調査を担当
