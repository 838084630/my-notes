# 経歴概要

大学卒業後、南京聯迪信息系統股份有限公司に入社し、Java ベースの Web システム開発を担当しました。その後、日本法人である株式会社リーディングソフトへ社内転勤し、システムエンジニアとしてクラウド・データ連携の基盤構築・運用に従事しています。

経験領域は、業務アプリケーションの開発から始まり、AWS、Azure、Kubernetes、Terraform、Datadog、Kafka、Flink を活用したクラウド基盤・運用設計まで広がっています。特に、アプリケーション開発とインフラ運用を接続する役割に強みを持ち、要件整理、設計、実装、テスト、障害対応、運用改善まで一貫して担える点が特徴です。

## 強み

-  Java を中心とした Web アプリケーション開発の実務経験
- AWS / Azure / Kubernetes / Terraform を用いたクラウド基盤構築・運用
- CI/CD パイプライン整備、監視設計、性能試験、障害調査、改善提案
- 5～6 名規模チームでのサブリーダー業務、顧客折衝、ドキュメント整理、コードレビュー・教育支援
- 技術を業務に落とし込み、運用品質や顧客価値へつなげる実践力
